## 1. ภาพรวมระบบ

```
ลูกค้า / พนักงาน (แอป LINE)
        │ กดปุ่ม Rich Menu → เปิด LINE MINI App
        ▼
หน้าแอป  index.html  ── GitHub Pages (cafe2325.github.io/2325-app)
        │ ขอข้อมูล / ส่ง ID token ของ LINE
        ▼
หลังบ้าน  Code.gs  ── Google Apps Script (Web App)
        │ ตรวจตัวตนกับ LINE · อ่าน/เขียน Sheet · ส่งแจ้งเตือน
        ▼
Google Sheet  "2325 App — หลังบ้าน"  (ฐานข้อมูล)
```

| ส่วน | อยู่ที่ไหน | ใครแก้ |
|---|---|---|
| ข้อมูลร้าน เมนู รางวัล พนักงาน | Google Sheet | เจ้าของ / ผู้จัดการ |
| Rich Menu, โปรโมชั่น, ข้อความตอบกลับ | LINE OA Manager | เจ้าของ / ผู้จัดการ |
| หน้าแอป (`index.html`) | GitHub `cafe2325/2325-app` | เจ้าของเท่านั้น |
| หลังบ้าน (`Code.gs`) | Apps Script ใน Sheet | เจ้าของเท่านั้น |
| ตั้งค่า LIFF / MINI App | LINE Developers | เจ้าของเท่านั้น |

## 4. งานประจำ: แก้จาก Google Sheet (ไม่ต้องแตะโค้ด)

แก้แล้วมีผลทันที ลูกค้าปิดแล้วเปิดแอปใหม่ก็เห็นข้อมูลใหม่

| อยากทำ | แท็บ | วิธี |
|---|---|---|
| เพิ่ม/แก้เมนู ราคา คำอธิบาย | เมนู | แก้ในแถว · หมวดเรียงตามลำดับที่เจอในชีต |
| เมนูหมดวันนี้ | เมนู | ติ๊ก **หมด** |
| ซ่อนเมนู | เมนู | เอาติ๊ก **แสดง** ออก |
| ติดป้ายเมนูแนะนำ | เมนู | ติ๊ก **แนะนำ** |
| ใส่รูปเมนู | เมนู | อัปโหลดรูปขึ้น Google Drive → แชร์ "ทุกคนที่มีลิงก์" → วางลิงก์ในช่อง **รูป (ลิงก์)** |
| เวลาเปิด ที่อยู่ เบอร์ แผนที่ | ตั้งค่าร้าน | แก้คอลัมน์ **ค่า** |
| ลิงก์ Grab / LINE MAN | ตั้งค่าร้าน | วางลิงก์ร้าน · เว้นว่าง = ขึ้นว่า "เร็วๆ นี้" |
| ประกาศบนหน้าแรก | ตั้งค่าร้าน | **ประกาศหน้าแรก** · เว้นว่าง = ไม่แสดง |
| เปลี่ยนกติกาแต้ม | บริการ | คาเฟ่ · **อัตรา** = กี่บาทได้ 1 แต้ม |
| เพิ่ม/แก้รางวัล | ของรางวัล | รหัส (เช่น R02) · ชื่อ · ใช้แต้ม · ติ๊ก **เปิดใช้** |
| เพิ่มพนักงาน | พนักงาน | ให้พนักงานเปิดลิงก์พนักงาน → คัดลอกรหัส `U...` → วางในแท็บ + ชื่อ + ติ๊ก **เปิดสิทธิ์** |
| พนักงานลาออก | พนักงาน | เอาติ๊ก **เปิดสิทธิ์** ออก (ไม่ต้องลบแถว) |
| โหมดแจ้งเตือน LINE | ตั้งค่าร้าน | **แจ้งเตือนทาง LINE**: `ปิด` / `ครบแต้ม` (แนะนำ) / `ทุกบิล` |
| เปลี่ยนโปรประจำสัปดาห์ | LINE OA Manager | ข้อความตอบกลับอัตโนมัติ → "ปุ่มโปรโมชั่น" → เปลี่ยนรูป/ข้อความ |

⚠️ **ห้ามเปลี่ยนชื่อหัวคอลัมน์ (แถวที่ 1) ทุกแท็บ** ระบบอ่านข้อมูลจากชื่อหัวคอลัมน์
🔒 แท็บ **สมาชิก** และ **ประวัติแต้ม** ถูกล็อกไว้ ระบบเขียนเอง ห้ามแก้ตัวเลขด้วยมือ

## 5. การใช้งานหน้าร้าน (พนักงาน)

1. คิดเงินใน POS ตามปกติ
2. เปิดลิงก์พนักงาน (ปักหมุดไว้ในกลุ่ม LINE พนักงาน)
3. กด **สแกน QR ลูกค้า** หรือพิมพ์รหัสสมาชิก / เบอร์โทร
4. กรอก **ยอดบิล** + **เลขที่ใบเสร็จ POS** → ตรวจแต้มในกล่องสีครีม → **ยืนยัน**
5. ลูกค้ามีแต้มครบ → การ์ด **แลกรางวัล** → กด **แลก**

กติกา: ทุก 100 บาท = 1 แต้ม · เศษบิลสะสมไปบิลถัดไป · ใบเสร็จหนึ่งใบให้แต้มได้ครั้งเดียว · 10 แต้ม = เครื่องดื่มฟรี 1 แก้ว

## 6. ✅ Checklist วันก่อนเปิดร้าน

- [ ] **ล้างข้อมูลทดสอบ**: แท็บ **สมาชิก** เลือกแถว 2 จนถึงแถวสุดท้าย → คลิกขวา → ลบแถว · ทำแบบเดียวกันกับแท็บ **ประวัติแต้ม** · (แท็บพนักงานเก็บไว้)
- [ ] ใส่ข้อมูลจริงในแท็บ **เมนู** (ลบเมนูตัวอย่างที่ไม่ใช้) + รูปเมนู
- [ ] แท็บ **ตั้งค่าร้าน**: เวลาเปิด-ปิด · วันหยุด · ที่อยู่ · ลิงก์ Google Maps · เบอร์ร้าน · Facebook/Instagram · ลิงก์ Grab/LINE MAN · รูปหน้าปก/โลโก้
- [ ] เปลี่ยน **ประกาศหน้าแรก** จาก "เร็วๆ นี้" เป็นข้อความวันเปิดร้าน (หรือเว้นว่าง)
- [ ] อัปเดตข้อความตอบกลับ **ปุ่มโปรโมชั่น** เป็นโปรเปิดร้านจริง
- [ ] เพิ่มพนักงานทุกคนในแท็บ **พนักงาน** + ปักหมุดลิงก์พนักงานในกลุ่มพนักงาน
- [ ] ซ้อมกับพนักงาน 1 รอบ: สมัครสมาชิก → สแกน → ให้แต้ม → แลกรางวัล
- [ ] เมนู **☕ 2325 App → ตรวจระบบ** ต้องเป็น ✅ ทั้งหมด
- [ ] เปิดแอปครั้งแรกของวัน (ปลุกหลังบ้าน) ก่อนลูกค้าคนแรกมา
- [ ] (ไม่บังคับ) ใส่ไอคอนแอปใน LINE Developers → Basic settings → Channel icon (รูปสี่เหลี่ยมจัตุรัส พื้นครีม)

## 7. กฎสำคัญเวลาแก้โค้ด (สำหรับเจ้าของ)

1. แก้ `Code.gs` ใน Apps Script แล้ว **ต้อง Deploy ใหม่ทุกครั้ง**: Deploy → Manage deployments → ✏️ → Version: **New version** → Deploy (URL เดิม)
2. แก้ `index.html` → อัปโหลดทับใน GitHub (ปุ่ม **+** → Upload files → Commit) → รอ 1–2 นาที
3. ถ้ามือถือยังเห็นหน้าเก่า ให้เปิดลิงก์โดยต่อท้าย `&v=ตัวเลขใหม่`
4. ถ้าขึ้นหน้าขอสิทธิ์ Google ต้องติ๊ก **Select all** ทุกครั้ง
5. สำรองโค้ด: เก็บ `Code.gs` ล่าสุดไว้ใน GitHub ด้วย (ไม่มีข้อมูลลับในไฟล์)
